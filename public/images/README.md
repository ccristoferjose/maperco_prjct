# Imágenes locales

Agrega estas imágenes (optimizadas) con los nombres exactos:

- `hero-fallback.jpg` — imagen `poster` del hero (1920×1080). Se muestra
  mientras carga el video o si el navegador no lo reproduce.
- `og-default.jpg` — imagen para compartir en redes (Open Graph), 1200×630.

Las imágenes de productos y proyectos usan URLs de Unsplash como placeholders
(ver `data/products.js` y `data/projects.js`). Reemplázalas por fotos reales de
Persianas Maperco para producción y actualiza el `alt` si es necesario.
